# Mod Reloader 0.1.0-beta — Changelog (English)

## Responsibility & consent (important)

- **Nothing is downloaded, extracted, or restarted silently.** JBR provisioning is now gated by an explicit consent screen.
- Before any action, the player is shown:
  - the pinned official JetBrains release page;
  - the exact `cache-redirector.jetbrains.com` download URL;
  - the pinned SHA-512;
  - the install directory and the restart action.
- The player must press **“Allow and continue”** before the runtime downloads, verifies, unpacks, or restarts. **Cancel leaves the game running with zero network/file/process side effects.**
- **Third-party runtime disclaimer:** JBR is a third-party runtime from JetBrains, not part of Mod Reloader. Mod Reloader only automates fetching, SHA-512 verification, and unpacking after the player allows it. The project is not responsible for third-party runtime availability, changes, or files; always verify the official link and checksum yourself.
- **No silent fallback or background download.** If you do not trust the source, cancel and install JBR manually.
- Platforms without a pinned JBR 21 asset (for example **Intel macOS**) have the Allow button disabled; only the manual path is offered.
- This release is distributed under **GPL-3.0-only**, without warranty. See `LICENSE`.

## JBR provisioning and failure recovery

- Added a consent screen with **Copy release page**, **Copy download URL**, **Open official page**, **Allow and continue**, and **Cancel**.
- Added a detailed manual guide:
  - exact official URL for the current platform;
  - exact target directory: `<gameDir>/jbr-21.0.11` (or next to the game directory);
  - required layout: a `release` file plus `bin/java` (`bin/java.exe` on Windows);
  - explicit warning: do **not** put JBR in `mods/`.
- Added **Re-check JBR** and **Open game folder** buttons. Re-check performs a live filesystem scan (no cache); if a usable JBR is found, it opens the restart confirmation.
- Download/extraction failures keep the game running and show the error; the player can retry, use the manual guide, or re-check after installing JBR manually.
- The download source is the official JetBrains `cache-redirector.jetbrains.com/intellij-jbr/` endpoint with pinned assets and SHA-512 values. The GitHub Release page is an official verification/index page; it does **not** host binary assets itself.

## Multiplayer validation

- **Late join (server hot-adds first, client joins later after restart-loading the same jar): PASS.**
  - Registry IDs matched the server exactly.
  - A real L2 action was performed: the client placed the hot-added block; both client and server confirmed the block state.
- **Client hot-add after connecting, followed by L2 placement: PASS.**
  - Both sides started without the jar; the client hot-added, the server hot-added after the client was ready, and the registry snapshot was applied.
  - Validated with the real content mod **Ex Nihilo: Satellitium 1.5.0** (`exnihilosatellitium:iron_ore_gravel`).
  - Validated with the JBR-tier stack **AE2 + GuideME** (`ae2:quartz_block`).
- **Create 6.0.10** remains **J2**: client hot-add succeeds, but `Player.aiStep` crashes while reading Ponder config (`Cannot get config value before config is loaded`). This is a known Create config boundary, not a harness failure.
- These results are dev-harness evidence, not a blanket compatibility promise.

## Fixes and engineering

- Fixed accessor/`@Invoker` interface rewriting for hot-added mixins (issue 65).
- Replayed `DataPackRegistryEvent.NewRegistry` for hot-added mods (issue 66).
- Preserved load-time access transformers when hot-added classes are redefined (issue 67).
- Added ModernUI opt-in adaptation (`-Dmodreloader.modernuiAdapter=true`); still J2.
- Added wrapper-jar unwrapping and nested-mod handling.
- Dedicated-server command gate: `/modreloader` requires permission level 2 (console/OP); regular players cannot hot-add.
- `./gradlew build` passes; **120/120** unit tests pass.

## Known limitations

- J2 examples: Sodium, Create, Jade (font dimming until restart), ModernUI (opt-in adapter), Xaero World Map.
- JBR auto-provisioning is not guaranteed: network/proxy reachability, only five pinned platform assets, and no Intel macOS asset.
- The consent UI and manual-recovery flow are compiled and unit-tested but still need a real Windows/PCL2 click-through before release.
- Multiplayer hot-add requires the same runtime and the same jar on both sides; a client without the hot-added jar is disconnected at login/datapack sync.
- License change: this release is GPL-3.0-only. The historical `v0.1.0` tag remains MIT and is not retroactively relicensed.
