# NoRestart 0.1.1 — Changelog (English)

(see [0.1.0.md](0.1.0.md); data source `docs/whitelist/mods.tsv`).

## Changes

- **JBR screens**: the consent, setup and manual-guide pages now clip their body text into a
  fixed, mouse-wheel scrollable viewport with a scrollbar. Fixes long text painting over the
  footer buttons at 854x480 with GUI scale 2. Build and 120/120 unit tests pass; visual
  re-check on a no-JBR session is still pending.
- **No-JBR player path (Windows real-machine)**: verified end to end — stock
  Microsoft OpenJDK 21.0.7, Create 6.0.10 triggers the JBR requirement, consent page,
  download of JBR 21.0.11, SHA-512 verification, unpack into `<gameDir>/jbr-21.0.11`,
  automatic relaunch with `enhancedRedefinition=true` and late AT enabled. Because the jar
  stays in `mods/`, Create loads at startup after the relaunch (no title-screen hot-add).
- **Architectury**: replay `SETUP`/`CLIENT_SETUP` and key mappings queued after startup events
  (fixes FTB Ultimine's empty shape registry NPE).
- **Cross-bus payloads**: snapshot each mod bus's payload listeners before construct and replay
  only the new ones during the payload phase (fixes FTB Ultimine login disconnect).
- **Enum extension hot-add**: supports Farmer's Delight `enumextensions`; adds
  `RecipeBookSettings.TAG_FIELDS`, `ClientHooks.RECIPE_BOOK_TYPES` and switch-map refresh for
  loaded classes; `$VALUES` is restored on rollback.
- **Embeddium / issue 69**: publishing to `LoadingModList` is now opt-in
  (`-Dmodreloader.publishModFile=true`); the default keeps the non-crashing "plugin skips
  itself" path. New video-settings redirect for hot-added mods with OptionsScreen /
  VideoSettingsScreen mixins plus a config screen. Embeddium remains J2.
- **Whitelist**: FerriteCore -> J2 (issue 71); Farmer's Delight -> J2 (issue 70).
- **Branding**: visible names unified as NoRestart; repo name, `modreloader` modId and jar
  file name are unchanged.
