## 1. 本版变化

### 1.1 JBR 页面正文不再遮挡按钮

- JBR **同意页 / 准备页 / 手动指南页**的正文改为固定视口裁剪 + 鼠标滚轮滚动 + 右侧滚动条；
  修复 854×480（GUI Scale 2，240 GUI 单位高）下长正文画到按钮上的问题。
- 构建与 120/120 单测通过；**真机视觉复验待下一次“无 JBR”会话**（本次真机是在修复前的构建上发现问题）。

### 1.2 无 JBR 玩家的自动准备路径（Windows 真机首次端到端）

以 stock JVM 模拟“没装 JBR 的玩家”，全链路通过：

1. `Microsoft OpenJDK 21.0.7`（`enhancedRedefinition=false`）→ 放入 Create 6.0.10 → 预检要求 JBR；
2. 同意页展示官方 release / 实际下载 URL / 固定 SHA-512 / 安装目录；
3. 点“允许并继续”后下载 JBR 21.0.11 → SHA-512 校验 → 解压到 `<gameDir>/jbr-21.0.11` → 自动重启；
4. 重启后 `JetBrains 21.0.11`、`enhancedRedefinition=true`、late AT enabled。

注意：JBR 重启时 jar 仍在 `mods/`，Create 按普通模组启动加载（日志 `already loaded in ModList`，
“无需重试”toast），**本次未走标题屏热加**；真正的 JBR 会话热加需在重启后把 jar 移出再触发。

### 1.3 兼容性修复

- **Architectury**：回放 `SETUP`/`CLIENT_SETUP` 与启动事件后入队的键位（FTB Ultimine 形状注册为空导致连锁 NPE）。
- **跨 mod 总线 payload**：构造前快照各 mod 总线的 payload 监听器，payload 阶段只回放新增项；
  修复 FTB Ultimine 经 Architectury 延迟注册时的登录断连。
- **枚举扩展热加**：支持 Farmer's Delight 的 `enumextensions` 形状；补
  `RecipeBookSettings.TAG_FIELDS`、`ClientHooks.RECIPE_BOOK_TYPES` 与已加载类的 switch map；
  失败回滚 `$VALUES`（仍受已知边界限制，见白名单）。
- **Embeddium / 问题 69**：`LoadingModList` 发布改为 `-Dmodreloader.publishModFile=true` opt-in，
  默认保留“插件自跳过、不崩”的路径；新增**视频设置重定向**（声明 OptionsScreen/VideoSettingsScreen mixin
  且有配置屏的热加模组）。Embeddium 仍为 **J2**。
- **白名单**：FerriteCore 转 J2（问题 71：`StateHolder` 活实例布局/删字段）；农夫乐事转 J2（问题 70）。

### 1.4 品牌

  历史文档保持原文。仓库名、modId `modreloader`、jar 文件名不变。

## 2. 已知限制（未变，节选）

- **皇后级**（删除/更新/已存在世界的世界生成/类级 AT 去 final）只提示重启；贵妃级仍为实验性 **add-only**，
  存档会依赖该模组。
- **stock JVM 的 AT 是硬边界**；JBR late AT 只覆盖成员级，需要增强会话。
- JBR 自动准备只在**本次会话**有效；跨会话需要启动器/整合包把实例 Java 设为 JBR。
- 热加成功后移出 jar 仍需重启；已提交的注册表内容不会随 jar 移除而消失。
- `candidate` / `fixing` 行不是发布承诺；平台实测仍只有 macOS dev 与 Windows/PCL2，Linux 未测。

## 3. 安装 / 升级

1. 准备 **Java 21 + NeoForge 21.1.265** 的 1.21.1 实例。
2. 把 `modreloader-1.21.1-0.1.1.jar` 放进 `mods/`（从 0.1.0-beta.1 升级时先关游戏再替换，文件名已变）。
3. 需要妃级/Mixin 热加时，再把可选的 `MixinRuntime`（modId `mr` ≥ 1.0.2）放进 `mods/`。
4. 首次需要 JBR 时点「为热加载增强环境做准备」→ 同意下载；之后本会话可直接热加。
